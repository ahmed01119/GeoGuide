# 📌 Project Idea

GeoGuide is a smart tourism and travel mobile application developed using Flutter to improve and support tourism in Egypt.

The application provides users with an interactive and intelligent experience for discovering tourist attractions, historical places, restaurants, hotels, and nearby services across different Egyptian governorates.

GeoGuide combines tourism services with Artificial Intelligence technologies to help users explore places more easily, recognize landmarks using AI Camera Scan, communicate with an AI Chatbot, and generate smart travel plans based on the number of travel days.

The main goal of the project is to make tourism exploration easier, smarter, and more enjoyable for both Egyptians and tourists.

---

# 🎯 Project Objectives

- Promote tourism in Egypt digitally
- Help users discover tourist places easily
- Provide smart tourism assistance using AI
- Improve trip planning experience
- Create a modern and user-friendly application

## 2️⃣ Navigate to Project Folder

